# Lampen Design UI Oberfläche

## Übersicht
Das Repository **lampen_design** bietet eine Web-Benutzeroberfläche zur Konfiguration und visuellen Steuerung von Beleuchtungsszenarien.

## Projektstruktur & Architektur
- `index.html`: Hauptdokument der Steuerungsoberfläche.
- `style.css`: Layout und Farbschema-Definitionen.
- `script.js`: Frontend-Logik zur interaktiven Lampenbedienung.

## Hauptfunktionalitäten
- **Visuelle Steuerung**: Einstellung von Farb- und Helligkeitswerten im Browser.
- **Touch-Optimierung**: Geeignet für Kiosk-Monitore und Bedienelemente.
- **Leichtgewichtige Umsetzung**: Direkte Ausführung ohne Frameworks.

## Ausführung & Nutzung
Die Datei `index.html` kann direkt im Browser geöffnet werden.
